# Multi-Cloud FinOps Dashboard

This project demonstrates a sample FinOps dashboard built to analyse cloud cost across AWS, Azure, and GCP.

The dashboard focuses on cost visibility, AI-related spend, untagged resources, and department-level accountability. It was created as a practical learning project to show how FinOps principles can be applied using sample cloud billing data and Power BI-style reporting.

## Project purpose

The purpose of this project is to show how cloud cost data can be turned into useful business insights for finance, engineering, product, and leadership teams.

The dashboard supports questions such as:

- Which cloud provider has the highest spend?
- How much of the spend is related to AI workloads?
- Which departments or teams are driving cost?
- How much spend is untagged?
- Where should governance or optimisation efforts begin?

## Key dashboard areas

- Total cloud spend overview
- Cost by cloud provider
- AI spend analysis
- Untagged resource visibility
- Department and team-level cost breakdown
- Tagging and governance insights

## FinOps focus

This project mainly supports the **Inform** phase of FinOps by improving visibility and accountability.

It also supports the **Optimize** phase by helping identify:

- Untagged resources
- High-cost services
- AI-related spend patterns
- Departments or teams needing better cost governance

## Tools used

- Excel / CSV sample data
- Power BI dashboard design
- GitHub documentation
- FinOps analysis approach
